# MVP 验收：五段连续之路

目标：纯前端可滚动长卷，路上依次经过 **5 段**；路过短提示；路边小实验可动手；进度 `localStorage`；无账号。

推荐顺序（主路从上到下或从左到右）：

1. 电与开关  
2. 逻辑门  
3. 简单程序 / CPU 步进  
4. 神经网络玩具  
5. Transformer 注意力直觉  

中间可用淡色「路肩」提示还有晶体管、OS、网络等，但不做实验（见 roadmap）。

---

## 全局验收（整站）

- [ ] `npm run dev` / `npm run build` 可用  
- [ ] 一条连续主路可滚动，**不是**关卡岛地图  
- [ ] 进入路段视口出现短提示（可关闭/自动淡出）  
- [ ] 每段有路边实验台（卡片），点开或展开后可交互  
- [ ] 进度写入 `localStorage`（建议 key 前缀 `tongyun-codeworld:`），刷新保持  
- [ ] 提供「重置进度」入口（设置或页脚即可）  
- [ ] 视觉符合 `docs/style.md`（暖奶茶底、圆角卡片）  
- [ ] 无后端、无登录

## 段 1：电与开关

**路过文案要点（示例方向，可润色，保持短）**

- 计算机最底层会的一件事：电路通或断。  
- 我们把这两种状态叫做 0 和 1——比特。

**路边实验交互**

- 至少 1 个灯泡 + 开关；建议 3 个开关对应 3 个比特，实时显示 `010` 这类字符串。  
- 点击/切换立即反馈，无需「提交」。

**通过条件（满足其一即可，实现时固定一种并写进配置）**

- 用户将比特图案调成预设目标（如 `101`），或  
- 用户完成引导：分别体验全关、全开，并点「懂了」。

**进度字段建议**

- `segments.switch.completed: boolean`（及可选 `lastPattern`）

---

## 段 2：逻辑门

**路过文案要点**

- 单个开关不够用；把通断组合成规则，就有了「逻辑」。  
- AND：都开才亮；OR：有一个开就亮；NOT：反过来。

**路边实验交互**

- 提供 AND / OR / NOT（可用点击切换门类型 + 2 输入开关，或简易连线）。  
- 出题：例如「只有钥匙 A 与 B 都打开时锁才开」→ 用户选对门与输入。  
- 输出用灯或锁图标表示。

**通过条件**

- 正确解出当前谜题一次（目标真值表或目标输出）。

**进度字段建议**

- `segments.gates.completed: boolean`

---

## 段 3：简单程序 / CPU 步进

**路过文案要点**

- 程序不是魔法：是一条条很笨的指令。  
- CPU 循环做：取出下一条 → 执行 → 改寄存器或内存。

**路边实验交互**

- 极简：程序列表 + 寄存器显示（如 R0、R1）+「单步」按钮。  
- 指令集示例（可删减）：`LOAD R0, 1` / `ADD R0, R1` / `STORE` / 或更简的「累加到 5」。  
- 步进时高亮当前指令（PC）。

**通过条件**

- 用户单步（或运行）跑完预设程序，最终寄存器/结果等于期望值。

**进度字段建议**

- `segments.cpu.completed: boolean`

---

## 段 4：神经网络玩具

**路过文案要点**

- 规则写不全时，可以让机器从例子里调「权重」。  
- 神经网络 = 很多小计算叠起来；拧权重，分类边界就会动。

**路边实验交互**

- 2D 画布上两类点（预设即可）。  
- 1～3 个可拖滑条（权重/偏置）；边界线或区域实时更新。  
- 显示简单准确率或「分对了几个」。

**通过条件**

- 准确率 ≥ 预设阈值（如 80%），或边界已把两类分开到可接受程度。

**进度字段建议**

- `segments.nn.completed: boolean`

---

## 段 5：Transformer 注意力直觉

**路过文案要点**

- 大模型把文字切成 Token，一个一个往后想。  
- 「注意力」：生成某个位置时，更盯着上文的哪些词——可用高亮示意，不必真跑模型。

**路边实验交互**

- 一句短中文或英文示例 + Token 块。  
- 用户点某个 Token（或「下一个词」位置），用透明度/色条显示预设注意力权重。  
- 旁白一句：「你看，它在看……」

**通过条件**

- 用户完成引导：至少点选 2 个不同位置并看到高亮变化，再确认「继续走」。

**进度字段建议**

- `segments.attn.completed: boolean`

---

## MVP 完成定义（Definition of Done）

五段均达到上文「通过条件」可被触发；全局清单全勾；README 中的本地跑命令有效；手机窄屏至少能竖向滚动浏览（实验可简化布局，不要求完美）。

**明确不做（MVP）**

- 真模型、训练、后端 API  
- 账号、云同步  
- 完整 OS/网络/语言段的深度实验  
- 音效必修、国际化和无障碍全套（有余力再加）
