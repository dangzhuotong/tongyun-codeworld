# 时代路段大纲（全景进阶路线图）

主路按第一性原理演进与系统抽象层级前进。从物理电平一路登顶系统与大模型架构师，始终保持「连续长卷长卷」探索，拒绝关卡岛。

## 总览（八大核心实操纪元）

| 序号 | 纪元路段 | 核心直觉（第一性原理） | 核心实操台 |
| :--- | :--- | :--- | :--- |
| **01** | **电、开关与比特编码** | 高低电平物理通断；8 个开关组合表达十进制与人类 ASCII 字符 | 8 位字节开关面板 + ASCII 实时翻译屏 |
| **02** | **逻辑门与加法器电路** | 串联为与、并联为或、反向为非；异或与与门物理合成 $1+1=10$ | 半加器动态电路 + 电平流动实时高亮 |
| **03** | **冯·诺依曼微机与指令节拍** | 时钟晶振方波心跳；取指-译码-执行-写回四拍流水线改变寄存器状态 | 单步时钟微处理器 + 寄存器与总线高亮 |
| **04** | **操作系统与虚拟内存** | 进程隔离与给程序“画大饼”；MMU 页表映射与缺页异常安全拦截 | 虚拟内存沙盘 + 跨进程野指针越界拦截体验 |
| **05** | **六大编程语言架构大比拼** | 没有银弹，只有架构权衡；C/Rust/Go/Java/Python/TS 内存与并发模型解构 | 六语言能力雷达 + 10 万并发连接压力测试沙盘 |
| **06** | **分布式与高并发架构沙盘** | 流量洪峰纵深防御：Redis 缓存分流 + Kafka 削峰 + Sentinel 熔断降级 | 50,000 QPS 流量洪峰中控台 + 架构防御实操 |
| **07** | **神经网络与梯度下降** | 规则无法穷尽时，让机器调旋钮；感知机权重与偏置在几何空间切分样本 | 2D 决策分界面拟合 + 模拟反向传播优化 |
| **08** | **大模型与 Transformer 推理架构** | 自注意力 QKV 点积向量检索；现代大模型自回归与 KV Cache 显存带宽墙瓶颈 | 自注意力热力图 + KV Cache 逐词显存演算沙盘 |

## 阶段验收标准

1. **零门槛直觉**：每个阶段均配备第一性原理 SVG 图解，拒绝死记硬背。
2. **多语言横向对照**：提供 C/C++、Rust、Go、Java、Python、TypeScript 的全面对比与架构师选型罗盘。
3. **真实可交互实操**：每个阶段都必须能动手调参数、点开关、拨动电平、观察系统反应。
4. **进度本地持久化**：进度保留在 `localStorage`（键 `tongyun-codeworld:progress`），可随时重置。
