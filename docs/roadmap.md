# 时代路段大纲（完整路线图）

主路按时间/抽象层级前进。**MVP 只做标 ★ 的五段**；其余为后续扩展，实现时仍保持「连续长卷上的一段」，不要改成关卡岛。

## 总览

| 序号 | 路段 | MVP | 直觉一句话 |
|------|------|-----|------------|
| 1 | 电与开关 ★ | 是 | 通断即信息：0 和 1 |
| 2 | 晶体管 | 否 | 用小开关控制大开关，才能堆出机器 |
| 3 | 逻辑门 ★ | 是 | AND/OR/NOT 组合出判断 |
| 4 | CPU / 简单程序步进 ★ | 是 | 指令一条条取指执行，状态在变 |
| 5 | 操作系统 | 否 | 多程序共用机器：调度与隔离的直觉 |
| 6 | 网络 | 否 | 包在路上跳，延迟与不可靠 |
| 7 | 编程语言 | 否 | 人话 → 机器步骤的翻译层 |
| 8 | 机器学习入门 | 否 | 从例子里调参数，而不是手写全部规则 |
| 9 | 神经网络玩具 ★ | 是 | 权重拧一拧，分类边界跟着歪 |
| 10 | Transformer / 大模型 ★ | 是 | Token 排队；注意力在「看谁」 |

## 各段说明（实现提示）

### 1. 电与开关 ★ MVP

- 路过：灯亮/灯灭就是两种状态，计算机先会这件事。
- 实验：点开关控灯泡；可并列 2～3 个开关显示比特串。
- 通过：至少完成一次「指定比特图案」或「全开/全关理解」。

### 2. 晶体管（后做）

- 路过：开关太费、太慢，需要能放大/受控的电子开关。
- 实验：简化示意「控制端 → 通断」即可，勿上真实电路仿真。

### 3. 逻辑门 ★ MVP

- 路过：把开关组合成「同时开才亮」「有一个开就亮」等规则。
- 实验：拖或点选 AND/OR/NOT，接输入解一个小密码锁。
- 通过：解开目标输出（或等价真值）。

### 4. CPU / 简单程序步进 ★ MVP

- 路过：机器按「取指令 → 执行 → 改寄存器/内存」循环。
- 实验：极简指令集（如 LOAD/ADD/STORE/JMP 里选 3～4 条），步进高亮 PC 与寄存器。
- 通过：跑完一段预设小程序，看到累加或交换结果。

### 5. 操作系统（后做）

- 路过：很多程序想用 CPU，需要轮流与保护。
- 实验：时间片小动画或多任务队列示意。

### 6. 网络（后做）

- 路过：数据拆成包，经多跳到达，可能丢、乱序。
- 实验：拖延迟/丢包看「聊天」或「下载条」的变化。

### 7. 编程语言（后做）

- 路过：高级写法被编译/解释成机器步骤。
- 实验：并排「一行源码 ↔ 几步伪指令」。

### 8. 机器学习入门（后做）

- 路过：规则写不全时，用数据调参数。
- 实验：一维拟合或两点分类，拖学习率看收敛。

### 9. 神经网络玩具 ★ MVP

- 路过：多层小计算单元，靠权重决定「怎么划分空间」。
- 实验：2D 点分类；拖 1～2 个权重或偏置，看决策边界。
- 通过：把两类点大致分开（或达到预设准确率阈值）。

### 10. Transformer / 大模型 ★ MVP

- 路过：文本被切成 Token；生成下一个时，模型会「更关注」上下文某些位置。
- 实验：固定短句；点某个输出位置，高亮注意力示意权重（可用预设矩阵，**不必**真跑模型）。
- 通过：完成一次「点选并读懂高亮在看谁」的引导交互。

## MVP 裁剪原则

1. 只做 ★ 五段，且在长卷上**按 1→3→4→9→10 顺序排列**（中间可留「以后延伸」的淡色路肩文案，标明晶体管/OS 等未实装，避免假装已做完历史）。
2. 未实装段可用很短的「路牌」占位，**不要**做可点的假实验。
3. 全路线实现时插入路牌位置，保持连续滚动，不改信息架构为地图。
