# 视觉风格：橦云手帐

整体气质：**暖、软、可写字的手帐页**，不是赛博霓虹，也不是默认 Vite 紫。

## 色板（CSS 变量建议）

| 角色 | 建议 | 备注 |
|------|------|------|
| 页面底 | 暖奶茶 `#F5E6D3` / `#F7EDE3` | 大面积背景 |
| 主路/卡片底 | 更浅奶霜 `#FFF8F0` | 实验台卡片 |
| 主点缀 | 抹茶绿 `#7A9E7E` / `#6B8F71` | 按钮、进度、通过态 |
| 强调点缀 | 蜜桃红 `#E8A0A0` / `#E8918A` | 少量：路过气泡边、重要开关 |
| 正文 | 暖灰褐 `#4A3F35` | 避免纯黑 |
| 次要文字 | `#8A7E72` | 提示、路肩 |
| 边框/分割 | `#E5D4C0` | 细线 |

阴影轻、低对比；圆角偏大（卡片建议 `16px`～`24px`）。

## 字体

- 系统栈即可：`"PingFang SC", "Noto Sans SC", "Segoe UI", sans-serif`
- 标题可略重；正文舒适行高 `1.6` 左右
- 不要用科技感过强的等宽做主 UI；等宽留给比特串、指令、Token

## 布局：长卷方向

**推荐默认：竖向长卷（自上而下滚动）。**

| | 竖向（推荐） | 横向 |
|--|-------------|------|
| 适合 | 手机 + 桌面；叙事「往下走」 | 桌面宽屏「沿路走」 |
| 滚动 | 原生纵向，省事 | 需横向滚或滚轮映射 |
| MVP | ✅ 优先 | 可作为后续切换 |

实现：一列 `segments` 纵向堆叠，中间用小路/虚线/渐变带连接；视差与装饰 SVG 可后加。

## 组件气质

- **路过提示**：圆角气泡，奶霜底 + 蜜桃描边或抹茶小圆点；自动出现，可点 ×；文案短。
- **实验台卡片**：圆角卡片、轻阴影、标题 + 一句话目标 + 交互区 + 「标记懂了 / 自动检测通过」。
- **主路装饰**：简单插画风（开关、小门、芯片轮廓、节点），线稿或平涂，避免写实照片。
- **进度**：顶部或侧边细进度条（抹茶），显示「第 x/5 段」或滚动百分比；勿做成游戏血条。

## 动效

- 短、缓：`200ms`～`300ms`；路过气泡 fade；开关有轻微缩放即可。
- MVP 不做复杂滚动剧情动画引擎。

## 反模式

- ❌ 大面积霓虹紫/电光蓝默认主题  
- ❌ 关卡地图选关 UI、徽章墙堆满首屏  
- ❌ 长文弹窗盖住整条路  
- ❌ 低对比灰字贴在灰底上（奶茶底上请用暖灰褐）

## 实现提示

在 `src/styles/tokens.css`（或等价）集中变量：

```css
:root {
  --bg-tea: #F5E6D3;
  --bg-card: #FFF8F0;
  --accent-matcha: #7A9E7E;
  --accent-peach: #E8A0A0;
  --text: #4A3F35;
  --text-muted: #8A7E72;
  --border: #E5D4C0;
  --radius-card: 20px;
}
```

有品牌插画再替换占位几何图形即可，MVP 几何足够。
