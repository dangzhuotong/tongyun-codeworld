## 三、 用户端到端走查动线（User Flow Walkthrough）

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户 (阿橦/学习者)
    participant Page as 连续主路页面
    participant Bubble as 路过气泡
    participant Lab as 展开实验台
    participant Store as LocalStorage

    User->>Page: 1. 打开页面，顺着中央虚线向下滚动
    Page->>Page: 2. 顶部导航实时更新：第 X/8 段 + 微缩进度条
    Page->>Bubble: 3. 视口滚入新路段，短气泡淡入浮现（1~2句通俗直觉）
    User->>Lab: 4. 点击“打开实验台”
    Lab->>Lab: 5. 顶栏展开查看第一性原理 SVG 图解（水龙头/加法器/MMU）
    User->>Lab: 6. 动手操作：拨动开关 / 单步时钟 / 切换六语言 / 拖动流量滑块
    Lab->>Lab: 7. 获得确定性物理反馈（例如 1+1 电流导通、10万并发内存对比、MySQL 降压）
    Lab->>User: 8. 达成条件，实验台顶部盖上绿色手帐印章【走过了 ✓】
    Lab->>Store: 9. 进度自动静默写入本地 localStorage
    User->>Page: 10. 收起或保持展开，继续顺着主路滑向下一个纪元，直到终章
```

## 四、 核心体验设计细节

1. **零阻碍自由滚动**：绝不强制“前一段没做完不准看后一段”。用户可以一路滑到底看完风景，也可以随时返回任何一段展开实操。
2. **多语言对比台**：将 C++、Rust、Go、Java、Python、TypeScript 的选项卡设计在显眼头部，切换时无重载刷新，能力雷达、机制卡片与代码区瞬时联动。
3. **视觉减负**：专业图示（如时钟波形、微机总线、系统拓扑）采用 SVG 矢量绘制，带微动效高亮，告别大段晦涩文字说明。
