# 产品愿景：代码世界

## 一句话

用一条**连续探索之路**，让人从「电与开关」走到「AI 大模型」，靠走、看、拧旋钮建立直觉，而不是背课件。

## 为什么做

- 阿橦自己想循序渐进理解「计算机从哪来、到大模型怎么连上」
- 以后可以挂 GitHub Pages，别人打开就能逛
- 衡量标准：**好玩、能走通直觉**；不追求百科全覆盖，也不做成刷题 App

## 核心交互：连续探索（不是关卡岛）

### 要做成

- **一条主路**：竖向或横向的可滚动长卷 / 俯视长路，场景随滚动从开关渐变成电路、程序、网络、模型
- **一步一步走**：进度 ≈ 你滚到了哪里 + 路边实验是否玩过；没有「选关地图」
- **路过自动短提示**：进入某段视口时弹出极短文案（约一两句），讲「这一段在干啥」
- **点路边实验台才动手**：主路上嵌着小实验卡片；点开或展开后拧旋钮 / 点开关 / 改一行，立刻看到结果
- **玩完继续走**：没有强制「通关解锁下一座岛」的硬墙；可用软提示「前面还有……」，MVP 可对未完成实验做轻提示，但主路始终可滚动浏览

### 不要做成

- ❌ 关卡岛 / 点亮地图 / RPG 选关大厅
- ❌ 教科书一页页翻、长篇 markdown 阅读站
- ❌ 必须注册才能存进度
- ❌ 一开始就堆完整计算机史与论文级细节

## 学习弧线（直觉，非考证）

电 → 开关与比特 → 逻辑门 → 简单计算/CPU 步进 →（完整路线还有 OS、网络、语言）→ 机器学习直觉 → 神经网络玩具 → Transformer / 大模型注意力直觉。

MVP 只截取最能「一眼懂」的 5 段，见 `mvp.md`。

## 情感与语气

- 像手帐里记的发现，不说教
- 文案短、具体、可动手验证
- 做错实验不惩罚：改一下又能看懂

## 成功长什么样

某人打开站点，顺着滚完这八段路，能口头说清：

1. 开关与电平怎么变成 0/1 与 ASCII 字符  
2. 门电路（XOR/AND）怎么物理组合出半加器 1+1=10  
3. CPU 在时钟脉冲下如何四拍流水线改变寄存器与内存  
4. 操作系统如何通过 MMU 页表给每个进程伪造虚拟内存并实现隔离保护  
5. 六大编程语言（C/Rust/Go/Java/Python/TS）在内存与并发层面的底层本质与架构取舍  
6. 高并发系统如何用缓存（Redis）、消息队列（Kafka）与限流熔断防守流量洪峰  
7. 神经网络如何用几何超平面和权重切分复杂数据  
8. 大模型自注意力在看谁，以及为什么现代推理受限于 KV Cache 显存带宽墙  

若这些说得出来，比多读十本理论大部头更有真实底气。
